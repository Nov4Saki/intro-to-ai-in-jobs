# الذكاء الاصطناعي في العمل - المحطات التفاعلية للجلسة الأولى

محطات تفاعلية مصمّمة لترافق الأجزاء الرئيسية لعرض الجلسة الأولى "مقدمة في الذكاء الاصطناعي: فهم الذكاء الاصطناعي ودوره في العمل اليومي" للمدرّب عبدالرحمن عيسى. يحتوي كل جزء على مزيج من الأنماط التفاعلية (ترتيب تسلسلي، توصيل ثنائي، تصنيف ثلاثي، فحص مسودات، خرافة أم حقيقة، واختيار من متعدد) لاختبار مهارات ذلك الجزء تحديداً.

## الروابط المستقلة حسب أجزاء العرض

- `/` - لوحة الجلسة الأولى وسؤال البداية السريع
- `/part-1-basics/` - الجزء 1: الأساسيات ومهام الذكاء الاصطناعي الأربع (الشرائح 5 - 10)
- `/part-2-approaches/` - الجزء 2: البرمجيات التقليدية مقابل الذكاء الاصطناعي (الشرائح 11 - 14)
- `/part-3-daily-life/` - الجزء 3: الذكاء الاصطناعي في حياتنا اليومية (الشرائح 15 - 17)
- `/part-4-expectations/` - الجزء 4: توقعات واقعية ودور المراجعة البشرية (الشرائح 19 - 21)
- `/part-5-office/` - الجزء 5: الذكاء الاصطناعي في المكتب وقواعد المؤسسة (الشرائح 22 - 24)
- `/part-6-workflow/` - الجزء 6: سير عمل بسيط من المُدخَل إلى القرار (الشرائح 25 - 27)
- `/part-7-myths/` - الجزء 7: مفاهيم خاطئة - خرافة أم حقيقة؟ (الشرائح 28 - 30)
- `/part-8-lab/` - الجزء 8 و 9: المختبر العملي والختام الشامل (الشرائح 31 - 37)

## التشغيل محلياً

```bash
npm install
npm test
npm run dev
```

## النشر التلقائي على GitHub Pages

يعمل ملف `.github/workflows/deploy.yml` تلقائياً عند الدفع إلى الفرع `main` لضبط المسار الأساسي وبناء النسخة الثابتة ونشرها على GitHub Pages، مع إبقاء مجلد `materials/` مستثنى من المستودع العام حفاظاً على شرائح ومفاتيح إجابات المدرّب.
