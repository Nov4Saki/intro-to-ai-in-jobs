# الذكاء الاصطناعي في العمل - الأنشطة التفاعلية (الجلسة 1)

أنشطة صفية تفاعلية مرافقة للجلسة الأولى "مقدمة في الذكاء الاصطناعي: فهم الذكاء الاصطناعي ودوره في العمل اليومي" للمدرّب عبدالرحمن عيسى.

## الروابط المستقلة للأنشطة

يولّد المشروع صفحة ثابتة لكل نشاط بحيث يمكن مشاركة رابط النشاط وحده أثناء الجلسة، أو مشاركة لوحة الجلسة الكاملة:

- `/` - لوحة الجلسة الأولى وسؤال التمهيد السريع
- `/triage/` - مختبر التصنيف: ذكاء اصطناعي أم أتمتة تقليدية أم غير مؤكد؟ (النشاط العملي - الجزء 8)
- `/matching/` - توصيل المفاهيم: ربط المهام الأربع وتطبيقات المكتب بأمثلتها (الجزء 1 والجزء 5)
- `/review-desk/` - طاولة المراجعة البشرية: اكتشف الخلل قبل الإرسال (الجزء 4 والجزء 6)
- `/myth-or-fact/` - خرافة أم حقيقة؟ مفاهيم شائعة تحت المجهر (الجزء 7)
- `/quiz/` - اختبار المواقف: مراجعة شاملة للجلسة الأولى (الجزء 9)

## التشغيل محلياً

```bash
npm install
npm test
npm run dev
```

## النشر على GitHub Pages

يتضمن المشروع ملف الإعداد التلقائي `.github/workflows/deploy.yml` الذي يضبط المسار الأساسي للمستودع تلقائياً ويصدر الملفات الثابتة إلى GitHub Pages:

1. أنشئ مستودعاً عاماً جديداً على GitHub (مثلاً `intro-to-ai-in-jobs`).
2. من إعدادات المستودع `Settings > Pages` اختر المصدر **GitHub Actions**.
3. ادفع الكود إلى الفرع `main`:

```bash
git remote add origin https://github.com/Nov4Saki/intro-to-ai-in-jobs.git
git push -u origin main
```

مجلد `materials/` مستثنى في `.gitignore` حتى لا تُنشر شرائح المدرّب ومفاتيح الإجابات في المستودع العام.
