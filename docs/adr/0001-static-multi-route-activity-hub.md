# Static multi-route hub organized by presentation parts

We publish all classroom checkpoints from a single static-exported repository where each presentation part compiles to its own directory path (`/part-1-basics/` through `/part-8-lab/`) alongside a root Session hub (`/`), while keeping raw trainer slide decks in `materials/` excluded from Git. Separate `github.io` repositories per exercise would multiply across the five-session course, and third-party classroom platforms impose juvenile themes, participant caps, or weak Arabic right-to-left typography. Static per-part directory routes let the trainer share one link right after each slide section to run a mixed sequence of mechanics, while keeping the Slide 34 trainer answer key out of the public repository.
